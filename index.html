Engineering Readme

Cara Kerja Playground

Arsitektur Pemrosesan Input

Event-Based Listener

Sistem merespon secara instan pada satu kali pemicu (contoh: tekan R untuk reset atau C ganti warna). Kelemahannya, jika digunakan untuk translasi pergerakan, akan bergantung pada jeda keyboard repeat rate bawaan sistem operasi.

State-Based Polling

Event input hanya mengubah nilai boolean di memori. Gerakan dikalkulasi oleh fungsi update() yang mengecek nilai tersebut setiap frame, menghasilkan pergerakan kontinu dan stabil tanpa jeda sistem.

Sistem ini menggunakan pendekatan yang memisahkan logika aplikasi dengan visualisasi. Posisi, ukuran, dan status input disimpan murni sebagai data. Fungsi perhitungan memanipulasi data tersebut, barulah API Canvas me-render ulang visualnya di setiap iterasi animasi (Animation Loop).

Challenge Report

Implementasi Fitur Interaktif

Penjabaran struktural dari setiap blok fitur yang diimplementasikan pada file skrip, meliputi tujuan fungsi yang dihasilkan, cara kerja logika kodenya, dan teori grafika yang melandasinya.

Keyboard Movement
Fungsi
Menggerakkan objek utama (persegi) dengan mulus menggunakan tombol WASD atau Panah.
Mekanisme
Modifikasi koordinat dilakukan dalam skala frame menggunakan metode state-based, dilengkapi batas kondisional (clamp) agar tidak melewati area ujung kanvas.
Konsep: state-based input, boundary clamp
Mouse Coordinate
Fungsi
Menampilkan teks berupa titik aktual koordinat (X, Y) dari pointer secara *real-time*.
Mekanisme
Event listener menangkap pergerakan mouse klien, mengkalibrasinya terhadap batas kanvas, dan fungsi teks me-render nilainya.
Konsep: client calibration, text rendering
Bouncing Objects
Fungsi
Entitas lingkaran memantul secara dinamis saat menabrak batas pinggir layar kanvas.
Mekanisme
Pengecekan posisi pusat objek. Jika menyentuh ambang batas resolusi kanvas, nilai vektor velocity dikalikan -1 sehingga arah geraknya berbalik instan.
Konsep: velocity inversion, edge collision
Follow Mouse Tracker
Fungsi
Sebuah lingkaran transparan yang menempel dan terus mengikuti arah pergerakan kursor pengguna.
Mekanisme
Secara pasif menetapkan koordinat pengambaran dengan merujuk langsung pada variabel penampung posisi mouse dari sistem *event listener*.
Konsep: continuous tracking, visual overlay
Click to Create Entity
Fungsi
Menciptakan lingkaran statis baru dengan warna dan ukuran acak tepat pada titik layar yang diklik.
Mekanisme
Menginjeksi data bentuk baru ke memori array of objects, yang kemudian otomatis dirender ulang oleh sistem iterasi grafis.
Konsep: array mutation, dynamic generation
Frame Visual Trail
Fungsi
Memberikan efek jejak bayangan pada pergerakan benda atau membuatnya menetap di layar.
Mekanisme
Memanipulasi fungsi pembersihan absolut dari kanvas. Efek pudar dicapai dengan menumpuk warna latar transparan via komposit destination-out.
Konsep: buffer clearing, composite operation
Iterative Processing
Fungsi
Menangani jalannya kalkulasi pergerakan banyak entitas bola independen secara bersamaan.
Mekanisme
Menjalankan struktur perulangan for...of pada koleksi data, di mana tiap objek mempertahankan data koordinat dan kecepatan aslinya secara terisolasi.
Konsep: array iteration, object isolation
